# yuru-sha GitHub defaults

This repository contains the default community health files shared by public repositories under `yuru-sha`.

Repository-specific files take precedence when a project needs different behavior.

## Shared defaults

- Pull request template
- Bug report Issue Form
- Feature request Issue Form
- Question / support Issue Form
- Contributing guide
- Security policy
- Support guide

Project-specific release configuration, `AGENTS.md`, licenses, and language/toolchain settings belong in each project or in `yuru-sha/project-template`.
